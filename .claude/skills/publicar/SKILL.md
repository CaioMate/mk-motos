# Publicar

1. `/verificar` precisa estar ✅ (se o projeto tiver código).
2. Delegue ao `rapido-git`: diga quais arquivos entram, o resumo da mudança, as linhas de coautoria e se o dono autorizou push sem perguntar (veja o CLAUDE.md do projeto / memória).
3. Se ele responder `ESCALAR` (arquivo sensível, conflito, autenticação): resolva você ou explique ao usuário em passos simples.
4. Conte ao usuário, em 2–3 linhas, o que foi publicado.
